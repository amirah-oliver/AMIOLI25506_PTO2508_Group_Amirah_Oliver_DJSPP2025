Podcast App (React)

A podcast discovery and listening application built with **React**, **Vite**, and **React Router**.

Users can:

- 🔍 Search podcasts

- 🎧 Listen to episodes

- ❤️ Save favorite episodes

- 🌙 Toggle between light and dark mode

- 📱 Enjoy a responsive design

---

## 🌐 Live Demo

https://your-vercel-link.vercel.app

---

## 📖 Overview

This application fetches podcast data from a public API and allows users to browse podcasts, explore episodes, save favourites, and play audio.

---

## ✨ Features

### 🔍 Discover Podcasts

- Search podcasts

- Filter by genre

- Sort results

- Pagination

### 📄 Podcast Details

- Dynamic routes

- View seasons and episodes

- Play episodes

- Save favourites

### 🎧 Global Audio Player

- Audio persists across pages

- Previous & Next controls

### ❤️ Favorites

- Save episodes

- localStorage persistence

### 🎨 UI

- Dark mode

- Mobile responsive

| Route | Description |
